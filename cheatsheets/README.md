# 📚 Caveman Linux Cheatsheets

Cheatsheets are reminders, not substitutes for lessons. Use them after you understand what a command changes and which system it targets.

| Reference | Use it when... |
| --- | --- |
| [Command Line](command-line.md) | navigating, reading, searching, or connecting commands |
| [Filesystem and Storage](filesystem-and-storage.md) | locating data or checking disks and mounts |
| [Users and Permissions](users-and-permissions.md) | checking identity, ownership, modes, sudo, or ACLs |
| [Processes and Services](processes-and-services.md) | inspecting work, signals, services, and logs |
| [Networking](networking.md) | checking addresses, routes, DNS, ports, and HTTP |
| [Server Operations](server-operations.md) | triaging health, logs, packages, backups, and security |

> Before a destructive or privileged command: confirm the host, current directory, exact target, expected result, and recovery path.
