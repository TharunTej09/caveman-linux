# 🧪 Caveman Linux Hands-on Labs

These labs turn the course stories into observable Linux behaviour. Use a disposable virtual machine and complete them in order.

| Lab | Mission | Best completed after |
| --- | --- | --- |
| [01 — Create a Linux VM](01-create-linux-vm.md) | Build a safe practice village | Chapter 02 |
| [02 — Host a Web Server](02-host-a-web-server.md) | Deliver a page to a client | Chapters 04 and 07 |
| [03 — Linux Permissions](03-linux-permissions-lab.md) | Protect shared treasure | Chapter 05 |
| [04 — Process Troubleshooting](04-process-troubleshooting.md) | Find a wasteful worker | Chapter 06 |
| [05 — Network Troubleshooting](05-network-troubleshooting.md) | Trace a broken road | Chapter 07 |

Every lab includes a starting state, tasks, verification, troubleshooting clues, cleanup, and an engineering challenge. Do not use production systems.
