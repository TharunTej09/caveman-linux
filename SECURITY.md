# Security Policy

## Reporting a Vulnerability

Do not publish a vulnerability, exposed credential, private key, or sensitive learner information in a public issue.

Use GitHub's private vulnerability reporting feature when it is enabled. Otherwise, contact the repository owner privately through the contact method shown on their GitHub profile.

Include the affected example, impact, safe reproduction steps, and a suggested correction when possible.

## Educational Examples

Commands in this repository are designed for disposable labs. Review targets, permissions, backups, recovery paths, provider controls, and organisational policy before adapting an example to production.

Never submit passwords, tokens, cloud keys, host keys, private keys, internal addresses, customer data, or production logs.
