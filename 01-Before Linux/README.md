# Before Linux

## Understanding Computers, Servers, and Operating Systems

Before learning Linux commands, you need to understand the machine Linux controls, the resources it manages, and the systems it helps build.

Instead of beginning with definitions to memorize, this module follows a caveman village. Each village problem introduces one real computing concept.

## 🎯 Why Should I Care?

Linux makes more sense when you first understand:

- What a computer contains
- Why hardware needs software
- Why computers need an operating system
- Why servers exist
- How clients and servers communicate

These ideas are the foundation of cloud platforms, containers, Kubernetes, data systems, and AI infrastructure.

## 🪨 Meet the Village

The course uses a small recurring cast:

| Character or Place | Technical Role |
|---|---|
| Hunter | User or client |
| Chief Grog | Linux and operating-system coordination |
| Village workers | Processes and computing work |
| Storage keeper | Server or storage system |
| Messenger and roads | Networking |
| Guards | Users, permissions, and security |

The analogy introduces each idea. The technical explanation then states how the real system works.

## 📌 Module Summary

By the end of this module, remember one connected idea:

> **Clients ask, servers provide, hardware performs the work, software provides the instructions, and the operating system organizes everything.**
