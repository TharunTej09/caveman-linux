# Before Linux

Before we learn Linux, we first need to answer a simple question.

Why was Linux created?

Computers existed before Linux.

Servers existed before Linux.

Networks existed before Linux.

So why did humans invent an Operating System?

Instead of memorising definitions, we will travel back thousands of years to a caveman village.

Every technical concept will first be explained using a simple caveman story.

Once you understand the story, understanding Linux becomes easy.

Welcome to the Caveman Village.
